# E04+E11: `find_shapes` (filters, artifact presets) and a sound cache fingerprint

## Hypothesis

One flexible, read-only query tool over the page structure cache can find objects by what they are (type, name,
ink, size, placement, layer flags, text, effects, PowerClips, overprint) and the cleanup artifacts that make bad
films (zero-size, invisible, stacked duplicates, off page, hairlines, empty text, specks, hidden-but-printable,
registration on art), fast enough for Good News page 1 (16.8k objects, under 10 s per call), with no false
positives on clean objects. It replaces the narrow search tools, and E01 T3 (client-side heuristics, 7 of 9 seeded
artifacts) becomes one call per preset with 9 of 9.

### `find_shapes`

- **Scope**: `pages` (default all), exact `layers`; master layers included (records say `master: true`).
  Presets look only at printable layers unless `filters.printable` is given.
- **Filters** (one JSON object, all must match): `ids`, `type` (name or code), `name` (exact, or case-insensitive
  glob), `text` (substring), `color` (the shared `core/colorspec.py` spec, matched with the inventory's `Matcher`
  on fills incl. fountain stops, outlines and every text run) + `color_part` + `color_tolerance`, ranges
  `outline_width`/`size`/`area`/`depth`, `intersects`/`inside` rectangles, `on_page` true/false/"crossing",
  booleans `printable`/`visible` (effective, inherited)/`locked`/`master`/`effect`/`overprint_fill`/
  `overprint_outline`, `powerclip` container/content. Lengths in `unit` (default the document unit).
- **Presets** (reasons in brackets): zero_size [zero_size, zero_area: zero height or width and no visible outline,
  so a 1 pt horizontal rule is not flagged]; invisible [no_fill_no_outline, zero_width_outline_only,
  ink_without_area (zero size, zero area, whitespace-only text), clipped_out (PowerClip content outside its
  container), hidden_object]; stacked_duplicates [stacked_duplicate, `duplicate_of` = the bottom copy];
  off_page [off_page, crosses_page_edge; PowerClip contents use their clipped bounds]; hairline [hairline,
  zero_width_outline; `outline_width_pt`; default threshold 0.1 mm]; empty_text [empty_text, whitespace_text];
  tiny [tiny, tiny_in_cluster (20+ under one parent), `parent_id`; default 0.1 mm]; hidden_printable_content
  [hidden_printable_layer]; registration_on_art [registration-colored object whose visible bounds overlap other
  printing art; text overlapping text (film labels) ignored].
- **Records**: `id`, `type` name, `page`, `layer`, `name`, `master`, `bounds` [left, bottom, right, top] in the
  document unit, `text` preview (40 chars), `reason` plus detail. Response: `count`, `counts` by reason,
  `by_page`, `summary` (tiny clusters by parent, duplicate groups), `shapes[offset:offset+limit]`, `next_offset`,
  `missing_ids`.
- **Paging**: the full result is cached (4 queries) and later pages are served from it while the bridge
  generation is unchanged and every page's cached structure is still valid: 0.3–0.4 s per page on Good News
  instead of a 6 s rescan. Offset 0 always rescans.
- **Selection**: `select=True` selects every match (not only the returned page) on one page: activates the
  document and page, builds one ShapeRange (one `Shapes.Range` per parent), reads the selection back
  (`selected_count`, `not_selected`); refuses when requested IDs are missing (selection unchanged) or more than
  one page is in scope. This subsumes `select_shapes_by_id`.
- **Reads**: base (name, bounds, visible) for every entry; paint (`tools.inks._PAINT`), stories and text runs
  (`_text_parts`), overprint, effect counts only when the query needs them. Duplicates hash on type, bounds
  (0.1 mm buckets) and paint identity (ink name and tint; palette IDs ignored, because one spot carries several),
  then read node positions for the candidates only and confirm every node and bound within 0.001 mm
  (order-insensitive). No all-pairs comparison: Good News p1 has 131 candidates in 60 buckets.

### Decisions

- **Native `FindShapes(Query=…)` is not used.** Its `Name` argument is an exact, case-sensitive match; `Empty`,
  `""`, `None` (typed null BSTR), `ArgNotFound`, `"*"` and omitting it all match only *unnamed* shapes, and it never
  enters PowerClips. On artifacts.cdr and structure.cdr (all shapes named) it returns 0. It is fast (36 ms for
  16.8k on Good News) but silently incomplete, so it cannot back a general filter; `FindShape(Empty, 0, sid)` has
  the same limit.
- **`cql` escape hatch (covers backlog E15)**: a boolean CQL expression over `$item`, evaluated through
  `Shape.Evaluate` (in `read_call`) only on shapes that passed the other filters. CorelDRAW's CQL reads properties
  only: `Delete`, `Duplicate`, `Move`, `ApplyNoFill`, `ConvertToCurves`, `CreateSelection`, `Rotate`,
  `SetPosition` all fail "is not a property"; `=` compares and `:=`/`$a = 1` are rejected (probed on a run-folder
  copy: nothing changed). Expressions naming `Application` are refused to keep queries on the shape. An error on
  any shape in scope fails the call with CorelDRAW's message and a hint to narrow by `type`.
- `select_shapes_by_id` removed; `get_ui_selection` kept.

### Cache fingerprint (E17a blind spot)

`page_layers` used `Page.Shapes.FindShapes(Empty, 0, True)` (recursive count) and `FindShapes(Empty, 0, True,
"@com.StaticID > max")` (new shapes). Both see only unnamed shapes. New finding: CQL turns a `Shapes` collection
into an array with `.toarray()`, and `filter`/`convert`/`count` then run in-process in O(n) (16,136 children:
`filter` 42 ms, `convert` of IDs 34 ms; `Shapes.filter` without `toarray` is an error). The new fingerprint is one
CQL call with, for every non-empty layer and every walked container (group, effect group, PowerClip): owner ID,
child count, children with `StaticID > max` (named or not), and children holding PowerClip contents (catches a
new PowerClip on a plain shape). Cost: Good News p1 revalidation 0.15 s (as before); a walk is cached only if
the fingerprint still matches right after it. Pages with many groups per shape are still walked every time.

Out-of-band test (`e04/probe_fingerprint.py`, and two acceptance checks): delete a named group member and add a
named rectangle into the same group (every count unchanged). E17a code: cache hit, new shape missing. New code:
stale detected, shape found. A named shape added to a new PowerClip is found and its container reported.

## Outcome

**Success.** One read-only tool finds objects by type, name, ink, size, placement, layer flags, text, effects,
PowerClips and overprint, and the nine artifact presets find 9 of 9 seeded artifacts on artifacts.cdr and every
seeded artifact on the new fixture with no false positives; Good News p1 presets take 1.5–7 s. Four tools removed, catalog size
unchanged. The cache fingerprint now sees named shapes and new PowerClips.

## Risks

- `stacked_duplicates` requires identical paint, including outline width; copies that differ only in outline
  width or in a fountain's stop colors (stops are read only for color queries) are or are not grouped
  accordingly. Effect-generated objects are excluded.
- `tiny_in_cluster` is a heuristic (20+ tiny inked objects under one parent); a page of stray specks dropped into
  one group would be called fine detail. Counts and `parent_id` are reported so an agent can judge.
- `registration_on_art` uses bounding boxes: a registration mark whose box overlaps art but whose ink does not is
  reported.
- Cached result pages can miss property-only UI edits made between paging calls (structure changes are caught);
  offset 0 always rescans.
- `select=True` cannot select objects on locked layers; it reports the mismatch.
- PowerClip contents get new StaticIDs when a document is reopened (E03); fixtures match by name.
- `cql` runs whatever property reads the expression names (read-only, but a slow expression is bounded only by
  the bridge's read interruption).

  vs 1.79 s) and could speed the walk itself; E17b or E21 could switch `read_entries` for whole containers.
- E14 text tools: records carry a 40-character preview only; font/size/overflow belong in `inspect_text`.
- E10 `render_plates` differences could link to a `find_shapes(filters={"intersects": bbox})` query.
- E19: `find_shapes` docstring is 1.9k chars; a shared filter/preset reference would shorten it.
