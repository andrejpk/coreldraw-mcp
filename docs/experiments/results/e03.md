# E03: ink inventory (`get_ink_inventory`)

## Hypothesis

If one read-only call returns, for each page, every ink with its source objects (fill, outline, every text run,
fountain stops, effect-generated objects, PowerClip contents), split by printability and placement, and the
plates the page's printable content implies, then an agent can build the film manifest and find the source of
an unexpected plate in one call instead of 165+. The plate prediction should match Ghostscript renders of the
page proofs on every sample and template page.

Why reduce `get_print_separation_settings` rather than fix its plate list: CorelDRAW's `Separations.Plates` is the
color set's configuration, not page content. It lists every ink of the set (including six Hexachrome plates no
page uses) and they are all `Enabled`, and `plate.Type` is unreadable. Filtering it to "used" plates would need
the whole inventory inside a settings call (8 s on Good News) and would still be per document, not per page. The
settings that change output (`spot_to_cmyk`, empty plates, a plate switched off) stay; per-page plates come
from `get_ink_inventory`.

### `get_ink_inventory` output (per page)

- `plates`: `print` (non-blank plates of a CorelDRAW print), `pdf_proof` (same for `export_page_proof_pdf`),
  `registration_only`, `estimated_only` (only RGB / other models / bitmaps), `hidden_printable_only`,
  `blank_spot_plates` (spots the page names but nothing marks: off page, clipped, whitespace-only text).
- `inks`: spot (name, tints, `palette_ids`, sRGB appearance), process `CMYK c/m/y/k` (plates = nonzero
  components), registration, RGB / CMY / Gray / other (plates estimated), bitmaps by color mode, unknown fills.
  Each has `objects` by state (`prints`, `hidden_printable`, `hidden_object`, `off_page`, `clipped`,
  `non_printable_layer`), `parts` (`fill`, `outline`, `outline_zero_width`, `text_fill`, `text_outline`,
  `text_whitespace`, `fountain_stop`, `pattern`, `bitmap`), `layers`, `flags` (`in_powerclip`,
  `effect_generated`, `transparent`, `locked_layer`, `master_layer`) and up to N `ids` (`id`, `layer`, `parts`,
  `state`, PowerClip/effect links; printing objects first).
- `layers` (flags, object counts, `hidden_printable`), `bitmaps` (mode, state), `warnings` with counts and IDs:
  `hidden_printable_ink`, `ink_only_off_page`, `similar_spot_names`, `similar_spot_colors` (CIE76 ΔE < 12 from
  CorelDRAW's `HexValue`), `spot_tints`, `spot_named_like_process`, `spot_palette_mismatch`,
  `zero_width_outline_with_ink`, `zero_size_with_ink`, `speck_with_ink` (< 0.1 mm), `fill_on_zero_area_shape`,
  `ink_on_whitespace_text`, `transparency_with_ink`, `fountain_mixes_inks`, `hidden_object_with_ink`,
  `unknown_fill_colors`, `bitmap_process`, `unreadable`, `text_runs_not_read`.
- `next_pages` when the time budget runs out (never needed so far: Good News, both pages, 7.4–8.4 s).

Text: one batched story read per layer (`Story.Fill`, `Story.Outline`, text). Only texts whose story fill or
outline is not uniform are read per character (CQL, about 5 ms per character inside CorelDRAW; direct-COM
`Story.Range` bisection was 20× slower). Whitespace-only runs are reported but do not make plates.

## CorelDRAW findings

- `FindShapes(Empty, 0, True)` counts only **unnamed** shapes and never PowerClip contents (0 on
  `structure.cdr`). E17a's recursive-count and newest-ID cache checks are therefore blind to named shapes; the
  per-container check (now including PowerClip counts) is what catches nested edits there.
- PowerClip contents get new StaticIDs when a document is reopened (structure.cdr: 16–23 in MANIFEST, 25–31 after reopening).
- `Story.Fill.Type` is 0 for mixed-fill text; `Story.Outline` raises for mixed outlines (and for some paragraph
  text). `Story.Range` is not callable from CQL. `TextRange` per-character access costs ~5 ms.
- `Color.HexValue`, `PaletteIdentifier` work in CQL for spots; `SpotColorID` raises for some custom spots;
  `Color.SpotAssign` wants a GUID. One spot name can come from several palettes (Kings, Jump, Good News:
  document palette and PANTONE coated), now flagged `spot_palette_mismatch`.
- `Outline.Width = 0` turns the outline off; renaming a palette spot copy (`SetName`) does not stick, so a
  `"354 C"` vs `"PANTONE 354 C"` fixture could not be built (name normalization is covered by code, not by a
  fixture).
- `Layer.Import` needs `(path, 0, app.CreateStructImportOptions())` through pywin32; legacy `import_svg` /
  `import_image` call `doc.Import`, which does not exist (broken, for E09).
- New pages created with `AddPages` copy page 1's layers (names and flags).

## Risks

- RGB, other color models and bitmaps get estimated plates (naive RGB→CMYK); the real output depends on color
  management. They matched the renders here (all four process plates).
- Contents of hidden objects (`Shape.Visible = False`) are assumed not to print; verified only for the PDF proof.
- `speck_with_ink` uses 0.1 mm: Good News p1 has 11,597 such objects (halftone-like art), so the count is high.
- Effect groups are now walked: exact-ID edit tools can resolve effect-generated objects, which CorelDRAW may
  refuse to edit.
- Mixed-run texts longer than 4,000 characters are reported as `text_runs_not_read`.
