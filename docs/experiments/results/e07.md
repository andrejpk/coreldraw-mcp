# E07+E06: exact-ID layers, transform, arrange, delete, group, PowerClip, create and import

## Outcome: success (ready to merge)

25 legacy name-based or active-page shape and layer tools are replaced by 11 exact-ID tools. Each one targets
`document_path` + `page_index` + StaticIDs, locates every target before the first change, is one undo step (a
failure part way is undone), verifies the after-state and drops the structure cache. Each one also refuses locked
layers, master layers, effect objects and PowerClip contents per object before changing anything. `import_file`
works now; it uses `Layer.Import` with `StructImportOptions`. `combine_shapes` stops and undoes itself after 35 s,
like `offset_silhouette`. CorelDRAW did not crash; it was the same process (PID 57244) throughout. The open-document
gate (`e13b/gate.py` through MCP, `e07/gate_inproc.py` in-process) ran before every session. Only documents under
`C:\CorelMcpLab` were ever open. Nothing on `Z:` was touched.

## Hypothesis

A handful of exact-ID tools with explicit units, anchors and references can replace the remaining legacy tools.
Those legacy tools look shapes up by name, act on the active page and are unverified, and some (`doc.Import`) are
broken. The replacements should be safer, cover more (multi-ID delete, master layers, z-order relative to
neighbours, import) and shrink the catalog. The E01/E13b production tasks should then need fewer calls.

## CorelDRAW findings (measured)

1. **`Shape.MoveToLayer` silently does nothing for a shape on a hidden layer.** No error is raised and the shape
   stays where it is; the read-back caught it. Moving onto a hidden layer works. `move_shapes_to_layer` shows
   hidden source layers during the move (inside the command group) and hides them again.
2. **`Layer.Import` onto a hidden layer fails** with "The server threw an exception" (RPC_E_SERVERFAULT). CorelDRAW
   kept running. `import_file` shows the layer during the import and hides it again.
3. **`ShapeRange.Group()` creates the group at the back of the active layer**, not where its members were.
4. `Layer.Import` / `ImportEx` need `StructImportOptions` through pywin32. Import lands centered on the page, on the
   given layer even of a non-active page, but makes that page active and selects the import. It is one undo step
   inside a command group.
5. `page.AllLayers` is in stacking order, front first: newer local layers first, then the masters where they stack.
   Verified by pixels on an exported PNG for local layers (master versus local order is inferred from the list, not measured). `Shapes.Item(1)` / `ZOrder 1` is the front. `MoveToLayer` puts a shape
   at the top of the layer. `ShapeRange.MoveToLayer` keeps relative order.
6. Layer flags and names: every change sets `Document.Dirty`, is undoable in a command group, and a master layer
   changed through one page's `AllLayers` changes on every page.
7. `RotationAngle` reads back cumulatively for rectangles, curves and groups after `RotateEx`.
8. Deleting shapes one by one inside a 16,000-child group costs about 0.13 s each: 300 Good News specks took
   **41.4 s** (near the bridge limit). One `ShapeRange.Delete` per layer took **3.6 s** for the same 300; undo took
   0.5 s.

## Risks

- `move_shapes_to_layer` and `import_file` briefly make hidden layers visible inside the command group (restored
  in `finally`). This sets the dirty flag; it does anyway with any edit.
- Moving shapes to another page is refused rather than supported. `move_shapes_to_layer` also refuses group
  members (ungroup first), and `group_shapes` groups only top-level shapes of one layer.
- `transform_shapes` with rotation cannot check the bounds analytically. It checks the anchor at `move_to` and the
  `RotationAngle` delta (skipped for types without a readable angle).
- `import_file` is validated with SVG and PNG only. A malformed file was not tried, because CorelDRAW may answer it
  with a modal dialog on the shared instance. The imported objects become the UI selection.
- Remaining legacy active-document tools: text (`set_text_content`, `set_text_style`, `fit_text_to_frame`,
  `check_text_overflow`, `create_text_frame`), the 8 exports, `add_guideline`, preflight and domain tools (E09,
  E14, E16).
